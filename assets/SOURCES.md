# Visual asset sources

Brand marks identify education, professional experience, and technologies. They remain the property of their respective owners.

| Asset | Official source | Presentation |
| --- | --- | --- |
| Shanghai Jiao Tong University seal | [University visual identity site](https://vi.sjtu.edu.cn/index.php/articles/bulletin/13) | Original transparent PNG, proportionally displayed on a white plate. |
| Alibaba | [Alibaba Group media resources](https://home.alibabagroup.com/en-US/resource-logos) | Original English logo, proportionally displayed on a white plate. Source: www.alibabagroup.com. |
| Bilibili | [Bilibili investor relations logo](https://ir.bilibili.com/media/mwvbaepv/logoenblue.svg) | Standalone wordmark extracted from the official header; original path geometry and color preserved, adjacent Investor Home text omitted. |
| Daft | [Daft repository favicon](https://github.com/Eventual-Inc/Daft/blob/main/docs/img/favicon.png) | Original transparent PNG. |
| Apache Spark | [Apache Spark repository](https://github.com/apache/spark/blob/master/core/src/main/resources/org/apache/spark/ui/static/spark-logo.svg) | Original vector wordmark. |
| Ray | [Ray repository](https://github.com/ray-project/ray/blob/master/doc/source/_static/img/ray_logo.svg) | Original vector logo. |
| Kubernetes | [Kubernetes repository](https://github.com/kubernetes/kubernetes/blob/master/logo/logo.svg) | Original vector geometry; intrinsic viewBox added for scaling. |

The AI Infrastructure chip icon, animated network, backgrounds, and layout are custom illustrations, not third-party brand marks. SVG plates embed their images locally and do not depend on external image services.

Language badges use [Shields.io](https://shields.io/) flat styling and white [Simple Icons](https://simpleicons.org/) marks, matching the reference profile. Badges are saved locally. C# uses the [Simple Icons 11.15.0 vector](https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/csharp.svg) because the current Shields built-in icon is unavailable.
